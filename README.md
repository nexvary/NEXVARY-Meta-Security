# NEXVARY Meta Security Lab

Android offline training application containing 100 safe, simulated security labs.

- Package: `com.nexvary.metasecuritylab`
- Target SDK: Android 15 / API 35
- Min SDK: API 24
- Offline by design: no INTERNET permission
- Arabic RTL interface
- 100 labs across 10 tracks
- Local progress tracking
- Historical Meta/Facebook cases are explicitly distinguished from synthetic training scenarios

This project is a training environment. It does not scan, probe, or exploit Facebook, Instagram, WhatsApp, or any external service.
